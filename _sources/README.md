# scverse x GSCN workshop

Workshop materials, organised by day:

- [Day 1](day_1/README.md) — QC, preprocessing, downstream analysis, batch correction,
  trajectory inference, fate probabilities
- [Day 2](day_2/README.md) — ligand-receptor interactions, differential abundance,
  spatial data, spatial domains and niches

Schedule and setup instructions are on the workshop site:
**https://scverse.org/gscn2026/**

All notebooks run in a single environment, `scverse-workshop`, built from
[`environment.yml`](https://github.com/scverse/202609_workshop_GSCN/blob/main/environment.yml)
in the repository root. Select the **scverse-workshop** kernel when you open a notebook.
